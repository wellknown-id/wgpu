Architecture

This custom webview engine is built entirely in Rust, using wgpu for GPU-accelerated rendering. It parses HTML and CSS, computes flexbox layout, rasterizes text with cosmic-text, and executes JavaScript with QuickJS — all without a traditional browser engine.

Technology Stack

wgpu

Cross-platform GPU abstraction providing Vulkan, DX12, and Metal backends for hardware-accelerated rendering

Taffy

Pure Rust flexbox layout engine that computes element positions and sizes from CSS properties

QuickJS

Lightweight embeddable JavaScript engine providing DOM interactivity and event handling

Rendering Pipeline

Each frame: HTML is parsed into a DOM tree, CSS styles are resolved and cascaded, Taffy computes flexbox layout, then wgpu draws rounded rectangles and text glyphs via instanced rendering. The entire pipeline runs at 60fps with minimal CPU usage.
